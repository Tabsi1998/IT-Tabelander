# IT-Tabelander PDF

Dolibarr module `ittabelanderpdf` (number 756230): PDF template **werkbank** in the IT-Tabelander design with the brand fonts for proposals, invoices (including credit notes, down payment and replacement invoices), orders, shipments, interventions, contracts, supplier price requests, purchase orders and goods receipts; branded e-mail templates; delayed, cancellable automatic sending of proposals, invoices and payment confirmations.

Documentation is German: [README-DE.md](README-DE.md), production steps in [docs/ROLLOUT.md](docs/ROLLOUT.md).
